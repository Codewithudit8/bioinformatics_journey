Problem kya hai? (Linear vs. Circular Genome)
Zyadatar bacteria ke genomes circular (gol) hote hain, lekin computations ko simple rakhne ke liye hum unhe ek seedhi line (linear string) ki tarah treat karte hain. Agar hum ek fixed size ka "sliding window" (ek frame) is linear string par chalayenge, toh sequence ke end mein aakar window aage nahi ja payegi. Iska matlab hum woh hissa miss kar denge jo end se ghoom kar wapas start se judta hai (jise wrap-around effect kehte hain).   Step 1: The "ExtendedGenome" Solution
Is problem ko bina kisi complex math ke solve karne ke liye hum ek bahut simple technique use karte hain jise ExtendedGenome kehte hain.   Kaise banta hai? Apne original Genome ke shuruwaati aade hisse (first half) ko copy karo aur usko genome ke end mein chipka do.   Kyu karte hain? Iska formula hai len(Genome)//2 characters ko copy karke end mein lagana. Iska sabse bada fayda yeh hai ki ab jab aapki sliding window original sequence ke end par pahuchegi, toh usko "wrap-around" data wahi aage mil jayega, aur circular genome ka koi bhi connection miss nahi hoga.   Step 2: "Symbol Array" ka Concept
Ab jab sequence artificial tareeke se lamba ho gaya, toh humein kisi specific nucleotide (jaise 'A', 'C', 'G', ya 'T') ka distribution check karna hota hai. Iske liye Symbol Array banaya jata hai.   Yeh Symbol Array bas ek record list hai jo yeh track karti hai ki aapki sliding window mein aapka target nucleotide kitni baar count hua hai.   Is array ka jo $i$-th element hota hai, woh yeh batata hai ki agar humari window ExtendedGenome ke $i$ position se shuru ho rahi hai (jiski length exact len(Genome)//2 hai), toh us particular frame mein woh symbol kitni baar maujood hai.   Step 3: Ek Example se Dry-Run (Image 2 wala case)
Aaiye isko ek example se dry-run karte hain. Maan lijiye aapka sequence Genome = "AAAAGGGG" hai, aur humein symbol 'A' ko count karna hai.   Length & Window Size: Genome ki total length 8 hai. Toh humari sliding window ka size hoga $8 / 2 = 4$.   Extend karna: Shuru ke 4 nucleotides ("AAAA") ko sequence ke end mein jod denge. Toh ExtendedGenome ban jayega: "AAAAGGGGAAAA".Window Slide karna: Ab hum 4-letter ki window ko ek-ek position aage badhayenge:Position 0: Pehli window hai "AAAA". Isme 'A' 4 baar hai. (Array ki pehli value $4$ ho gayi).   Position 1: Ek step aage khiske, window bani "AAAG". Isme 'A' 3 baar hai. (Array ki dusri value $3$ ho gayi).   Position 2: Window bani "AAGG". Isme 'A' 2 baar hai. (Array ki teesri value $2$).   Position 3: Window bani "AGGG". Isme 'A' 1 baar hai. (Array ki chauthi value $1$).   Position 4: Window bani "GGGG". Isme 'A' 0 baar hai. (Array ki paanchvi value $0$).
