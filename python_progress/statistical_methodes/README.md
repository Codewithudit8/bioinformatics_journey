1. average.py
Calculates the mean of a given list of numbers. 

2. variance.py
Calculates the variance to see how spread out the data points are from the average.

3. standard_deviation.py
Calculates the standard deviation. This script uses the logic of both average and variance to find the final deviation value.

### How to run
You can run any of these scripts directly in the terminal:

bash
python3 average.py
python3 variance.py
python3 standard_deviation.py
