##This script is a single-file showcase covering five key concepts##

Dictionaries: Iterating through key-value pairs (.items()) and extracting isolated lists of keys and values.

List Comprehensions: Writing clean, one-line loops with conditional logic (filtering multiples of 3 and 5).

String Slicing: Extracting specific substrings using the [start:end:stride] syntax.

Lambda & Filter: Decoding a "garbled" string using an anonymous lambda function, and comparing it against a simpler .replace() method.

Binary Operations: Performing basic arithmetic directly with binary literals (using the 0b prefix).

How to Run
Make sure you have Python 3 installed, then run the script from your terminal:

Bash
python basics.py
The terminal will output the results step-by-step, making it easy to follow along with the code!
