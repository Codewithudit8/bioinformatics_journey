This repository tracks my learning journey into bioinformatics. The current scripts focus on fundamental Python programming concepts that are essential for data analysis.

## Topics Covered
- *List Generation:* Creating numerical lists using range().
- *List Slicing:* Extracting specific portions of data (e.g., getting odd numbers using step slicing).
- *Lambda Functions:* Using anonymous functions for quick, inline operations.
- *Filtering (filter()):* Extracting specific data from lists based on conditions (e.g., finding multiples of 3, or filtering strings).
- *List Comprehensions:* A concise way to create and filter lists (e.g., generating squares of numbers).

## Usage
Simply clone this repository and run the Python scripts in your preferred IDE or terminal to see the output of the basic operations.
